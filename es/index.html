Perfil

Todo es un sistema. Si funciona y da resultados reales, es un buen sistema. Siempre es posible mejorar un sistema.

Mi experiencia abarca desde la programación en Python, el prototipado, la preparación de datos y dashboards, hasta la creación y el lanzamiento de productos digitales globales y proyectos de comercio electrónico.

Como entiendo todo el proceso—desde la construcción y desarrollo web (HTML/CSS) y aplicaciones web, la integración de pasarelas de pago y checkout, hasta la creación de funnels y landing pages funcionales—me manejo tanto en el código como en la lógica de negocio y sé cómo transformar una idea en un proyecto autosuficiente.

Además, diseño y lidero programas de formación y cursos de TI para la administración pública, escuelas y academias de informática. Creo que un sistema bien diseñado siempre supera a la motivación pura.

Estoy abierto a colaboraciones remotas y a tiempo parcial (part-time).

I. Software, datos y lógica de sistemas

Silent Scout

Un escáner de WiFi personal en un microcontrolador ESP32, programado en MicroPython. Recopilación y procesamiento de datos de redes locales usando Pandas, con los datos posteriormente visualizados en una app de Streamlit. El dashboard muestra ubicaciones individuales, la intensidad de la señal, la seguridad de las redes detectadas y su identificación. Se prioriza la seguridad y un enfoque de campo táctico de bajo perfil ("low-profile").

Código en GitHub Aplicación en vivo

Peru Regional Telemetry

Una aplicación web interactiva que se conecta a una API REST externa para monitorear datos atmosféricos en 7 regiones del Perú. Sirve como una demostración práctica de un pipeline ETL completo, usando Pandas para la limpieza de datos y Matplotlib + Streamlit para la visualización dinámica.

Código en GitHub Aplicación en vivo

Deep Reader

Un script simple en Python (menos de 50 líneas de código) creado como una herramienta personal para una lectura profunda y enfocada. Toma la URL de cualquier artículo, la limpia de anuncios, banners de cookies y rastreadores invasivos, y entrega el texto principal en un formato Markdown limpio.

Código en GitHub Aplicación en vivo

Cyber EDC

Creación de un Cyber-EDC resistente y portátil (unidad USB personal). El disco tiene 2 modos de funcionamiento: una unidad operativa activa con herramientas digitales seleccionadas y respaldo cifrado de datos personales, y un modo pasivo con la capacidad de arrancar sistemas operativos (Tails, Kali) en la computadora anfitriona. Utiliza Ventoy para el arranque del sistema operativo.

II. Despliegue web, aplicaciones web y productos digitales

The Partner Pact

Un producto digital global completamente automatizado. Un juego de cartas táctico de comunicación para parejas, listo para descargar e imprimir. Creado como un desafío durante un sprint de 4 días. El proyecto involucró prototipado rápido, diseño de producto en HTML/CSS, desarrollo del sitio web (landing page) con localización multilenguaje e integración de una pasarela de pago segura.

Andes Resilience Web

Una landing page para un programa de entrenamiento físico y oferta de servicios. Enfoque en un diseño limpio orientado primero a dispositivos móviles (mobile-first). Construido sobre una arquitectura sin backend (página web estática) utilizando HTML5 y Pico CSS.
