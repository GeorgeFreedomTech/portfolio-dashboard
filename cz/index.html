Profil

Všechno je systém. Pokud to funguje a má to reálné výsledky, je to dobrý systém. Zlepšení systému je možné vždy.

Moje zkušenosti sahají od programování v Pythonu, přes prototypování, přípravu dat a dashboardů po budování a launch digitálních produktů a e-commerce projektů.

Protože mám přehled o celém řetězci — od stavby a vývoje webu (HTML/CSS) a web apps, integraci platebních bran, checkout, stavbu funkčních funnels & landing pages — orientuji se v kódu i v byznysové logice a vím, jak rozvinout nápad v soběstačný projekt.

Kromě toho se navrhuji a vedu tréninkové programy a IT kurzy pro státní správu, školy a IT akademie. Věřím, že dobře navržený systém vždy porazí čistou motivaci.

Jsem otevřený pro part-time projekty, remote spolupráci a konzultace (např. pro nezávislý pohled na architekturu, volbu platformy a nástrojů).

I. Software, data a systémová logika

Silent Scout

Osobní WiFi skener na mikrokontroleru ESP32, naprogramovaný v MicroPython. Sběr a zpracování dat o lokálních sítích s pomocí Pandas, data jsou následně vizualizována ve Streamlit app. Dashboard ukazuje jednotlivé lokality, sílu a zabezpeční zjištěných sítí a jejich identifikaci. Důraz je kladen na bezpečnost a terénní "low-profile" přístup.

GitHub Kód Live app

Peru Regional Telemetry

Interaktivní webová aplikace, která se připojuje k externímu REST API a monitoruje atmosférická data v 7 regionech Peru. Slouží jako praktická ukázka kompletní ETL pipeline s využitím Pandas pro čištění dat a Matplotlib + Streamlit pro dynamickou vizualizaci.

GitHub Kód Live app

Deep Reader

Jednoduchý Python skript (méně než 50 řádků kódu), vytvořený jako osobní nástroj pro soustředěné hluboké čtení. Vezme URL zadaného článku, očistí jej od reklam, cookie lišt a invazivních trackerů a doručí čistý text ve formátu Markdown.

GitHub Kód Live app

Cyber EDC

Vytvoření odolného, přenosného Cyber-EDC (osobní USB disk). Disk má 2 módy fungování - aktivní operační jednotka s vybranými digitálními nástroji a šifrovanou zálohou osobních dat a pasivní režim s možností zavedení operačních systémů (Tails, Kali) na daný počítač. Využívá Ventoy pro bootování OS.

II. Webové stránky a digitální produkty

The Partner Pact

Plně automatizovaný globální digitální produkt. Taktická komunikační karetní hra pro páry - ke stažení a následnému tisku. Vytvořeno jako challenge během 4denního sprintu. Projekt zahrnoval rychlé prototypování, produktový design v HTML/CSS, stavbu webu (landing page) s vícejazyčnou lokalizací a integraci zabezpečené platební brány.

Andes Resilience Web

Landing page pro program fyzického tréninku a nabídku služeb. Důraz na čistý mobile-first přístup. Postaveno na zero-backend architektuře (statická web page) s využitím HTML5 a Pico CSS. Nabízí integrovanou podporu pro dva jazyky. Extrémně rychlé načítání a optimalizovaný konverzní funnel.

NOOMAD Masterclass

Live online workshop zaměřený na transformaci nápadů v automatizované digitální produkty s využitím bezplatných, low-code a no-code nástrojů a AI. Je využita případové studie reálného produktu. Workshop je zaměřen na přístup k tvorbě produktového designu, integraci a využití open-source nástrojů a automatizaci prodejů.
