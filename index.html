Profile

Everything is a system.

A good system does not have to be complicated. It simply needs to work, serve a purpose and produce a useful result. And there is usually room to make it simpler.

My professional background is a mix of education, science, data analysis, business and technology. I enjoy moving between these worlds: understanding a problem, learning what I need, building something practical, testing it and then explaining what I learned to someone else.

Teaching is an important part of what I do. I design and deliver IT courses, mentor individual learners and turn technical subjects into structured learning materials. My technical work is closely connected to this: I use Python, web applications, data, AI tools and physical computing mainly to explore ideas, solve practical problems and keep learning.

I am less interested in technology for its own sake than in what it can actually do. A small, reliable solution is often more useful than a sophisticated one that nobody needs.

The same approach influences how I work with people. I value independence, responsibility and competent leadership. I am happy to take ownership, but I also want to understand the context and learn from people who know more than I do.

📍 Currently based in Peru during a planned sabbatical, where I continue teaching, building, writing, learning Spanish and exploring ideas around technology, resilience and practical self-reliance.

After returning to Czechia, I am interested in work where people, knowledge, technology and practical problem-solving meet.

I. Software, Data & Systems Logic

Silent Scout

A personal WiFi scanner using an ESP32 microcontroller, programmed in MicroPython. Collecting and processing local network data using Pandas, with data subsequently visualized in a Streamlit app. The dashboard displays individual locations, signal strength, security of detected networks, and their identification. Focus is placed on security and a tactical "low-profile" field approach.

GitHub Code Live App

Peru Regional Telemetry

An interactive web application that connects to an external REST API to monitor atmospheric data across 7 regions of Peru. It serves as a practical demonstration of an end-to-end ETL pipeline, using Pandas for data cleaning and Matplotlib + Streamlit for dynamic data visualization.

GitHub Code Live App

Deep Reader

A simple Python script (under 50 lines of code) created as a personal tool for focused deep reading. It takes any article URL, strips it of ads, cookie banners, and invasive trackers, and delivers the core text in clean Markdown format.

GitHub Code Live App

Cyber EDC

Building a rugged, portable Cyber-EDC (personal USB drive). The drive has 2 operational modes—an active operational unit with selected digital tools and encrypted personal data backup, and a passive mode with the ability to boot operating systems (Tails, Kali) on any host computer. It utilizes Ventoy for OS booting.
